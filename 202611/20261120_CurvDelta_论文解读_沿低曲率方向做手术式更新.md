# 把"别乱动"焊进参数里：CurvDelta 用低曲率空间给大模型做手术

你有没有碰到过这种事——拿十万道数学题把模型微调一轮，GSM8K 蹭蹭涨到 36 个点，回头测一下 TriviaQA，常识问答从 35.7 掉到 22.5。新能力是学到了，老本事被顺手削掉一大截。更头疼的是合规场景：法务要求把某批版权内容从模型里"忘掉"，遗忘指标确实压下去了，可模型连正常问答都开始胡言乱语，model utility 从 63 掉到 39。

这类事我自己在调遗忘任务的时候撞过好几次。当时能做的无非是往 loss 里加正则、混一点回放数据、或者把梯度往"不伤害旧任务"的方向掰一掰。管用吗？多少管点。但总有一种在打补丁的感觉——约束是外挂的，训练一跑起来，优化器该怎么走还怎么走，你只能在旁边拉缰绳。

上周翻到一篇新 paper，思路一下子把我拽住了：它不拉缰绳，它直接把"允许往哪儿走"这件事写进了参数更新的结构里。优化器再花哨也跑不出去。这个转换我觉得挺漂亮的，值得掰开聊聊。

---

先给一段带判断的**核心摘要**：这篇 CurvDelta 处理的是大模型适配里那个老毛病——改一个行为，别的本事跟着塌。它的做法不是再加一个正则项，而是先在预训练模型附近量一下"保持损失"的局部曲率，找出那些动了也不怎么改变模型输出的方向（低曲率方向），然后把可训练的增量死死限制在这个子空间里。为了在 LLM 上算得动，作者用 K-FAC 把曲率矩阵拆成 Kronecker 积，再做一次可分离的双侧投影，顺手派生出一个低秩版本 CurvLoRA。效果上，代码生成任务 Llama-2-7B 上把下游均分和保持均分同时做到全场第一（40.5 / 44.4），TOFU 遗忘的 Forget Quality 达到 -0.1，几乎与从头重训不可区分。我的判断：这不是底层突破，是一次几何视角下相当干净的方案整合，最值钱的是"约束内建在参数化里"这个论证，以及一份能算出来的局部保持性上界；但"接近从头重训"这句话在 MUSE 上站不太稳，得打个折看。

## 🎯 问题动机：为什么"别破坏原有能力"这么难

先把两类任务摆在一起看。一类是**能力学习**（capability learning），比如灌数学题、灌代码，让模型长出新本事；另一类是**定向遗忘**（selective unlearning），比如把某个虚构作者的问答对、某本书的原文从模型里抹掉。表面上一个加一个减，骨子里是同一件事：更新必须是**选择性的**。目标行为要变，无关行为要纹丝不动。

作者把这个诉求写得很规整。给一个任务集 $\mathcal{D}_{\mathrm{task}}$ 装"想要的变化"，再给一个保留集 $\mathcal{D}_{\mathrm{pres}}$ 标记"不许变的行为"，可以是预训练数据的代表，也可以是一份代理语料。定义保持损失为模型输出相对原模型的偏离：

$$\mathcal{L}_{\mathrm{pres}}(\bm{\theta}) = \mathbb{E}_{x \sim \mathcal{D}_{\mathrm{pres}}}\big[d(\bm{z}_{\bm{\theta}}(x), \bm{z}_{\bm{\theta}_0}(x))\big]$$

其中 $d$ 取 logits 上的 KL 散度 $D_{\mathrm{KL}}(p_{\bm{\theta}_0} \| p_{\bm{\theta}})$。于是整个适配变成一个带约束的优化：

$$\min_{\bm{\theta}} \mathcal{L}_{\mathrm{task}}(\bm{\theta}) \quad \mathrm{s.t.} \quad \mathcal{L}_{\mathrm{pres}}(\bm{\theta}) \le \varepsilon$$

学新能力和定向遗忘，差别只在 $\mathcal{L}_{\mathrm{task}}$ 怎么取。这个统一挺舒服的，一个框架吃两类任务。

老办法有三条路，各有各的别扭。

**把保持塞进 loss**：拉格朗日松弛 $\mathcal{L}_{\mathrm{task}} + \lambda \mathcal{L}_{\mathrm{pres}}$，回放（Replay）和 EWC 那类正则都算这一支。麻烦有两个。$\lambda$ 跟你真正能容忍的漂移 $\varepsilon$ 没有对应关系，训完才知道漂了多少，等于旋钮和结果之间隔了一层黑箱；再就是这本身就是个多目标优化，两个梯度打架，尤其在遗忘任务里冲突格外凶，一个要往下压、一个要往上托，谁也说服不了谁。

**投影任务梯度**：GEM、以及这篇里作为 baseline 的 CrispEdit，每步把梯度投影到"不干扰旧任务"的方向。这条更聪明，但作者点出一个很实际的漏洞：投影是加在梯度上的，不是加在最终更新上的。SGD 下两者等价，可一旦换成 Adam，二阶矩按坐标做不等比缩放，投完的梯度被各个方向放大缩小一通，**实际的 $\Delta\bm{W}$ 又跑出那个子空间了**。约束相当于只在半路上生效。

**限制在正交 / 零子空间**：OPLoRA、CorDA、MiLoRA 这些参数高效方法，或按 SVD 主成分、或按正交性把增量圈在某个子空间里。问题在于，这些子空间是拿参数或表示的几何启发式划出来的，跟"通用能力会不会掉"只是间接相关。你划得再漂亮，也没法保证模型输出真的不变。

所以作者把问题（Q）提得很直接：怎么把保持约束**直接焊进 $\Delta\bm{\theta}$ 的参数化**，同时还留够适配需要的自由度？

说实话，我第一反应是"这不就是把投影提前吗"。往下读才发现，提前这一步带来的差别比想象中大——它把约束从训练过程里的软限制，变成了参数空间里的硬边界。

## 🧠 方法核心：在损失地形里找那条平坦的路

### 从曲率到"低曲率子空间"

整篇的地基是一个二阶展开。因为 $d$ 在 $\bm{z}_{\bm{\theta}} = \bm{z}_{\bm{\theta}_0}$ 处取最小值且一阶导为零（Bregman 散度都满足这个性质，KL 是其中一种），在 $\bm{\theta}_0$ 附近做泰勒展开时，一阶项直接消失，连二阶链式法则里那个残差项也因为 $\partial_{z_k} d = 0$ 被抹掉，剩下的 Hessisan 恰好等于广义 Gauss–Newton 矩阵：

$$\mathcal{L}_{\mathrm{pres}}(\bm{\theta}_0 + \Delta\bm{\theta}) \approx \tfrac{1}{2}\Delta\bm{\theta}^{\top}\bm{H}_{\mathrm{pres}}\Delta\bm{\theta}, \quad \bm{H}_{\mathrm{pres}} = \bm{G}_{\mathrm{pres}} \succeq \bm{0}$$

半正定这点很关键，它保证后面的特征分解有意义。把 $\bm{G}_{\mathrm{pres}}$ 拆成特征对 $(\lambda_i, \bm{u}_i)$，写 $\Delta\bm{\theta} = \sum_i \alpha_i \bm{u}_i$，约束就变成 $\sum_i \lambda_i \alpha_i^2 \le 2\varepsilon$，而更新长度的平方是 $\sum_i \alpha_i^2$。

到这一步，结论几乎是逼出来的：**同样长的更新，把力气集中在 $\lambda_i$ 小的特征方向上，付的保持代价最小**。所谓"低曲率空间"，就是 $\bm{G}_{\mathrm{pres}}$ 的尾部（trailing）特征空间。不是随便挑个子空间，是从"保持损失对参数扰动有多敏感"这个度量里直接长出来的。

### LLM 上算不动？K-FAC 加双侧投影

想法漂亮，落地第一道坎就来了：$\bm{G}_{\mathrm{pres}}$ 是 $d \times d$ 的，LLM 里 $d$ 动辄几十亿，存都存不下，更别说求尾部特征向量。

作者搬来的是 2015 年 Martens 和 Grosse 的 K-FAC。这套东西本来是给自然梯度做预条件的，思路是把 Fisher 矩阵按层做块对角近似，再把每一层的块写成两个小矩阵的 Kronecker 积。对一个线性权重 $\bm{W}_l \in \mathbb{R}^{d_{out} \times d_{in}}$：

$$\bm{G}_{\mathrm{pres}}^{(l)} \approx \bm{K}_l^{in} \otimes \bm{K}_l^{out}, \quad \bm{K}_l^{in} = \mathbb{E}[\bm{a}_{l-1}\bm{a}_{l-1}^{\top}], \quad \bm{K}_l^{out} = \mathbb{E}[\bm{g}_l \bm{g}_l^{\top}]$$

$\bm{a}_{l-1}$ 是输入激活，$\bm{g}_l$ 是该层输出梯度，都在 $\bm{\theta}_0$ 上用保留集估一次。存储从 $(d_{in}d_{out})^2$ 掉到 $d_{in}^2 + d_{out}^2$，这是能跑起来的前提。顺带说一句，K-FAC 这条脉络后来还喂给了 Shampoo、Sophia 那一批二阶优化器，算是老树一直在发新芽。

Kronecker 结构有个好用的性质：方向 $\bm{u}_i^{out}(\bm{u}_j^{in})^{\top}$ 的曲率正好是 $\lambda_i^{out}\lambda_j^{in}$。于是"找低曲率方向"可以拆成在两个因子里各找尾部特征向量，作者管这叫 **factorwise spectral truncation**。取一个谱能量阈值 $\gamma \in (0,1)$，让 $r_{out}$、$r_{in}$ 分别是累计能量刚够 $\gamma$ 的最小秩，缓存前 $r$ 个 leading 特征向量，补空间上的投影就是：

$$\bm{P}^{out} = \bm{I} - \bm{U}_h^{out}(\bm{U}_h^{out})^{\top}, \quad \bm{P}^{in} = \bm{I} - \bm{U}_h^{in}(\bm{U}_h^{in})^{\top}$$

真正施加到权重上的增量，是那个双侧投影：

$$\Delta\bm{W} = \bm{P}^{out}\,\bm{\delta}(\bm{\phi})\,\bm{P}^{in}$$

维度是 $(d_{out}-r_{out})(d_{in}-r_{in})$。保留空间里最大的曲率写成 $\kappa = \lambda_{r_{out}+1}^{out}\lambda_{r_{in}+1}^{in}$，该层对二次保持损失的贡献被 $\tfrac{1}{2}\kappa\|\Delta\bm{W}\|_F^2$ 压住。$\gamma$ 拧大一点，$\kappa$ 和可用维度一起单调不增——**一个旋钮，同时管住曲率上界和更新自由度**，这个设计我觉得是全文最精巧的一处。

跟 CrispEdit 那种 product-spectrum thresholding 比，差别在"可分离"。后者在完整的 Kronecker 特征基上逐元素打掩码，不可分离，得缓存整套基和一个乘积 mask；CurvDelta 只缓存两个因子的 leading 特征向量，投影还能直接作用到低秩因子上，不用物化稠密矩阵，CurvLoRA 就是这么来的。代价是它会丢掉"一个因子特征值小、另一个大，乘起来还行"的混合方向。作者拿"平坦方向本来就很多"（Sagun、Ghorbani 那批实证）和"优化本来就是低维的"来给这个取舍背书，坦率讲，这个辩护偏文献类比，没在这篇自己的设定里直接测被丢方向的影响。后面我会再提。

### 两种参数化，和一份局部保证

有了固定的低曲率空间，剩下就是怎么在里面表示增量。稠密版 CurvDelta 直接让 $\bm{\delta}_l$ 是个零初始化的全尺寸矩阵，参数量 $d_{out}d_{in}$，投影后有效自由度 $(d_{out}-r_{out})(d_{in}-r_{in})$，把整个保留空间铺满。低秩版 CurvLoRA 走 LoRA 分解：

$$\bm{\delta}_l = \bm{B}_l\bm{A}_l, \quad \Delta\bm{W}_l = (\bm{P}_l^{out}\bm{B}_l)(\bm{A}_l\bm{P}_l^{in})$$

参数量降到 $r(d_{out}+d_{in})$，施加的增量秩最多 $r$，仍在同一低曲率空间内。两侧投影通过缓存的特征基隐式完成，不必把大矩阵摊开。

流程浓缩成 Algorithm 1 大概是这样：

```
输入: θ0, D_task, D_pres, γ, 目标权重集 T
1. 在 θ0 上用 D_pres 估一次 K-FAC 因子 (K_in, K_out)
2. 按 γ 缓存 leading 特征基, 得到 P_out, P_in
3. 冻结 θ0, 初始化 δ (或 B, A) 为 0
4. 每一步: 构造 ΔW = P_out δ P_in, 用 L_task(θ0+Δθ) 更新 δ
5. 结束: 由最终 δ 重算 Δθ 并合并回 θ0
```

关键在于几何只估**一次**，投影矩阵和 base 参数全程冻结，投影内建在参数化里。所以不管你用 SGD 还是 Adam，实际施加的 $\Delta\bm{W}$ 从头到尾都待在规定空间里。这一点正是它和梯度投影拉开差距的地方，Figure 3 会把这个差距用数据摆出来。

理论收口是 Theorem 1，把逐层的界加起来：

$$\mathcal{L}_{\mathrm{pres}}(\bm{\theta}_0+\Delta\bm{\theta}) \approx \tfrac{1}{2}\Delta\bm{\theta}^{\top}\bm{G}_{\mathrm{pres}}\Delta\bm{\theta} \le \tfrac{1}{2}\sum_{l \in \mathcal{T}}\kappa_l \|\Delta\bm{W}_l\|_F^2$$

只要 $\sum_l \kappa_l\|\Delta\bm{W}_l\|_F^2 \le 2\varepsilon$，在局部二次模型下就算满足约束。$\kappa_l$ 由几何定死，$\|\Delta\bm{W}_l\|_F^2$ 由优化轨迹（学习率、步数）决定——**曲率决定单位位移的代价，增量范数决定总位移**，两个量一起管住保持损失。这份上界我喜欢，它把 $\gamma$、$\kappa$、学习率这些散落的旋钮串成了一句能讲清的话。

不过得把话说全：这是在 $\bm{\theta}_0$ 邻域、二阶近似、块对角 K-FAC 三重假设下的**充分条件**，不是全局保证。训练走远之后曲率会漂移，这一点后面看 Figure 4 时会再戳一下。

## 🧪 实验：数据会说话，也会藏话

### 设置

能力学习这边，数学用 MetaMathQA 抽 100K 条微调，测 GSM8K 和 MATH；代码用 CodeFeedback 抽 104K 条，测 HumanEval 和 MBPP。通用能力保持看 TriviaQA、NQ-Open、MMLU 三个。保留集 $\mathcal{D}_{\mathrm{pres}}$ 只从 FineFineWeb 里抽了 **256 条**——这个数字记一下，后面消融会证明它有多省。模型用 Gemma-3-1B 和 Llama-2-7B 的预训练 base，LoRA 系方法 rank 固定 128 / 32。对手排得很满：FT、Replay、CrispEdit、LoRA、PiSSA、MiLoRA、CorDA、OPLoRA。

下面的表里，`Avg.` 是对应分组内均分，`ALL` 是五个原始任务分数（两下游 + 三保持）的总平均，越高越好。

这是全文最漂亮的一组数。Llama-2-7B 上 CurvDelta 下游均分 40.5、保持均分 44.4、ALL 42.8，**三项同时是全场第一**。不是"少忘一点换少学一点"的取舍，是两头都往上走：下游压过 Replay 的 40.3 和 FT 的 38.5，保持压过 LoRA 的 44.0。Gemma 上同样 ALL 22.1 居首，保持均分 23.7 最高。正文那句 "this pattern is strongest for code generation" 我认，代码任务确实比数学更能显出这套几何的价值——大概因为代码微调对输出分布的扰动更集中，低曲率方向更容易既学到东西又不碰通用知识。

### 主实验三：定向遗忘

遗忘用 TOFU（Forget 5% / 10%，Llama-3.1-8B-Instruct 等三个 3B–8B instruct 模型）和 MUSE Books（Llama-2-7B），目标函数覆盖 GradDiff、NPO、SimNPO。TOFU 看 Forget Quality（FQ，越接近 0 越接近从头重训）、forget QA 概率 FP（越低越好）、model utility MU（越高越好）；MUSE 看逐字记忆 VerbMem、知识记忆 KnowMem、保留知识 Retain KnowMem，都用 ROUGE。下表是 SimNPO 主结果。

| 方法 | TOFU 5% FQ / FP / MU | TOFU 10% FQ / FP / MU | MUSE VerbMem↓ / KnowMem↓ / Retain↑ |
|---|---|---|---|
| Retrain（金标准） | – / 10.8 / 63.2 | – / 10.6 / 64.6 | 14.2 / 29.5 / 68.6 |
| Original | -11.8 / 99.0 / 62.7 | -26.8 / 99.2 / 62.7 | 99.7 / 46.6 / 69.1 |
| FT | -0.5 / 13.0 / 54.6 | -1.4 / 14.4 / 38.9 | 23.3 / 27.6 / 46.8 |
| CrispEdit | -0.2 / 12.7 / 59.3 | -1.9 / 16.9 / 42.0 | 14.3 / 29.2 / 53.8 |
| LoRA | -7.4 / 22.6 / 63.1 | -13.5 / 18.2 / 64.6 | 31.6 / 31.1 / 53.4 |
| VILA | -2.2 / 19.8 / 62.9 | -8.4 / 17.7 / 66.8 | 29.8 / 34.8 / 59.0 |
| OPLoRA | -4.5 / 21.6 / 64.5 | -15.5 / 27.4 / 62.9 | 18.5 / 29.3 / 58.2 |
| CurvLoRA | -1.3 / 7.6 / 62.6 | -3.7 / 3.4 / 62.5 | 20.0 / 31.2 / 57.6 |
| **CurvDelta** | -0.1 / 6.3 / 63.3 | -1.1 / 6.5 / 63.2 | 11.6 / 32.1 / 55.8 |

TOFU 这边确实硬。FQ 是 log10 的 KS 检验 p 值，越贴近 0 说明和 Retrain 越难区分，CurvDelta 的 -0.1 / -1.1 是两个 split 里最强的；FP 6.3 / 6.5 压得很低；MU 63.3 / 63.2 贴着 Retrain 的 63.2 / 64.6，几乎不掉效用。反观 FT，10% split 的 MU 直接塌到 38.9，遗忘把模型训坏了——这个对比很能说明"约束更新空间"为什么比"只改目标函数"更稳。CurvLoRA 在 10% split 把 FP 压到 3.4，比 CurvDelta 的 6.5 还狠，但 FQ 掉到 -3.7，属于忘过头、偏离了 Retrain 分布，这个细节作者也如实写了。

MUSE 就得泼点冷水了。CurvDelta 的 VerbMem 11.6 是全场最低，连 Retrain 的 14.2 都压过去了，逐字遗忘做到位。可 Retain KnowMem 只有 55.8，输给 VILA 的 59.0、OPLoRA 的 58.2、甚至自家 CurvLoRA 的 57.6，离 Retrain 的 68.6 差了 **12.8 个点**。KnowMem 32.1 也不是最低，FT 的 27.6 和 CrispEdit 的 29.2 都比它低。所以"更好的遗忘–保持平衡""retention 接近从头重训"这套话，在 TOFU 上稳稳立得住，搬到 MUSE 上就有点勉强了。摘要里那句概括写得偏满，我是读到 Table 3 才反应过来要拆开看。

### 消融：到底是哪一步在起作用

![图2：delta 空间构造的消融](https://www.mulanai.com/fs/files/1120_f039e519_ablation.png)

*图2：在 TOFU Forget 10%（Llama-3.2-3B-Instruct + SimNPO）上的四组消融。(a) 投影基对比，橙 CurvLoRA / 蓝 High-curvature / 绿 Random subspace，横轴是学习率（单位 1e-4）、纵轴 model utility；(b) 谱能量阈值 γ，橙点标 0.5–0.9，灰菱形是 Retrain、× 是 LoRA；(c) 保留数据比例 0.25×–4×，蓝点几乎挤在同一小块。圆环是默认设置，虚线阴影标出 Retrain 及优于它的区域。*

(a) 是我最看重的一组。三个投影基**维度对齐**，只换方向：低曲率（CurvLoRA）的 utility 全程稳在 0.66 以上，高曲率和随机两个变体在大学习率下掉到 0.645 附近，遗忘还更弱。这说明起效的不是"把空间压小"这个动作本身，而是"按保持曲率挑方向"这个选择。控制变量做得很干净。

(b) 里 $\gamma$ 从 0.5 拧到 0.9，QA 概率大致从 0.15 往 0.09 走，utility 稳在 0.65–0.666，默认 $\gamma=0.9$ 用圆环标出。(c) 更让人省心：保留数据从 forget set 的 0.25 倍到 4 倍，蓝点全挤在一小块里，说明估曲率根本不依赖大保留集——回到前面那个 256 条，工程上这几乎可以忽略不计。

不过看图得留个心眼：(b)(c) 的纵轴只截了 0.61–0.67 这一窄条，utility 的实际波动不到 1.5 个点，视觉上被放大了不少。"robust" 这个结论我信，但图表的呈现方式确实把微小的差异拉得挺显眼。

![图3：参数化 vs 梯度投影](https://www.mulanai.com/fs/files/1120_a255939f_deltagra.png)

*图3：横轴 Forget Quality（越右越好）、纵轴 model utility（越上越好）。蓝色实线方块是 CurvDelta，灰色虚线圆点是 CurvDeltaGrad（同样的低曲率投影，但改成每步投影梯度），数字标注学习率 / 1e-5。蓝线整体压在灰线右上方，差距在高学习率处更明显。*

Figure 3 是把方法部分那个论断钉死的实验。同样的 $(\bm{P}^{out}, \bm{P}^{in})$，一个把投影内建进 $\Delta\bm{W} = \bm{P}^{out}\delta\bm{P}^{in}$ 的参数化，一个只在 Adam 每步前投影梯度。学习率 2e-5 时 CurvDelta 到 FQ 约 -1.1、MU 约 66.3，CurvDeltaGrad 只有约 -1.7 / 66.1；拧到 5e-5，两边 utility 都往下掉，CurvDelta 依然领先。等于用数据坐实了"Adam 的不等比缩放会把更新踢出子空间"——这个坑不亲自踩过很容易忽略，作者单独拎出来做一组消融，我觉得挺有诚意。

![图4：保持性与效率分析](https://www.mulanai.com/fs/files/1120_96e8fcbf_analysis.png)

*图4：(a) 上图经验 retain-set KL 随 γ 单调下降，下图 K-FAC 二次近似（实线）与谱上界（虚线）保持同一趋势；(b) 各方法经验 retain-set KL 横向条形，Dense 组 CurvDelta 0.149 远低于 CrispEdit 0.752 / FT 0.624，Low-rank 组 CurvLoRA 0.013 最低；(c) 总时长对峰值显存散点，CurvDelta 约 1000s / 39GB，图上标了相对 CrispEdit 省 59.5% 时长、36.5% 显存。*

(b) 的条形图挺能说明问题：Dense 组里 CrispEdit 0.752、FT 0.624、CurvDelta 0.149，差了四倍多；Low-rank 组 VILA 0.473、LoRA 0.043、OPLoRA 0.042、CurvLoRA 0.013。保持集上的 KL 确实被压得很低。

(a) 我得停一下。下图的二次近似（实线）始终落在谱上界（虚线）下方，三条学习率曲线趋势和经验 KL 一致， $\gamma$ 越大三个量一起降——这些都成立。但上下两图的数值尺度差了好几个数量级：经验 KL 在 0.02–0.08，二次模型和上界在 $10^{-5}$ 到 $10^{-9}$。作者自己在正文里也写 "operates on a smaller numerical scale"，坦白承认了。所以这组更像"趋势验证"，不是"定量吻合 Theorem 1"。坦率讲，把局部二次模型当成训练结束时真实保持损失的替身，中间还隔着一段不短的距离。

(c) 的效率账也要拆开算。CurvDelta 约 1000 秒、39GB，相对 CrispEdit 的约 2500 秒、41GB 标了省 59.5% 时长和 36.5% 显存，没错。但 **39GB 仍然高于 FT 的约 28GB**，"省显存"是相对另一个曲率方法说的，不是相对全量微调。而且 wall-clock 里已经把曲率估计算进去了，作者强调 eigenbasis 依赖 base model / $\mathcal{D}_{\mathrm{pres}}$ / $\gamma$，算一次能跨任务、跨目标、跨参数化复用——这个摊薄逻辑成立的前提是：同一个 base checkpoint、同一份保留集、同一个 $\gamma$ 底下要连着做很多次适配。只做一次的话，前置的 K-FAC 估计并不划算。

## 💡 我的判断

先说我觉得值钱的地方。

**视角转换是真的漂亮**。整条线上，约束一直被当成 loss 里的软惩罚，或者优化过程里的中途投影；这篇把它挪到参数化的结构里，变成"允许模型往哪儿走"的硬边界。一旦投影写进 $\Delta\bm{W} = \bm{P}^{out}\delta\bm{P}^{in}$，用什么优化器都无关紧要，Adam 那种坐标缩放再也踢不出去。这个论证比一堆"给 LoRA 加个正交约束"的工作干净得多，Figure 3 还专门做了对照，不是嘴上说说。

**一套几何吃两类任务**。学新能力、定向遗忘，加上 GradDiff / NPO / SimNPO 三种目标，共用的是同一份在 $\bm{\theta}_0$ 上估出来的 eigenbasis。工程上这种"算一次、复用多次"的性质，往往比榜单上多涨一两个点更实用。

**给了能讲清楚的界**。Theorem 1 把 $\gamma$、$\kappa$、$\|\Delta\bm{W}\|_F$ 串成一句话：曲率决定单位位移的代价，增量范数决定总位移。哪怕它只是局部充分条件，至少让"旋钮往哪拧更保险"有了依据，不是纯调参玄学。

再说我皱眉的地方。

**保证是局部的、一次性的**。二阶泰勒 + 块对角 K-FAC + 只在 $\bm{\theta}_0$ 估一次曲率，训练走远之后 preservation landscape 自己会变。Theorem 1 的 $\varepsilon$-feasible 只在起点邻域成立，全文没有验证训练结束时真实的 $\mathcal{L}_{\mathrm{pres}}$ 是否真的 $\le \varepsilon$，Figure 4(a) 那个尺度差已经把这个问题摆到台面上了。

**接近从头重训这句话得拆开看**。TOFU 上 MU 63.3 对 Retrain 63.2，贴得漂亮；MUSE 上 Retain KnowMem 55.8 对 68.6，差 12.8，连 VILA 的 59.0 都没比过。摘要把两类基准并成一句"retention close to the from-scratch retraining reference"，读的时候容易被带过去。

**baseline 选得有点巧妙**。能力学习里排了一整列 PEFT（PiSSA、MiLoRA、CorDA、OPLoRA），却没放持续学习 / 模型合并里那些更硬的对手——task vector 插值、TIES / DARE 这类合并、或者带 KL 约束的偏好式训练。而 Replay 在 Llama 数学推理上 ALL 40.2 反超所有方法这件事，正文只用"narrowing the retention gap"轻轻带过。要证明"几何约束优于数据回放"，这组对照其实是最该正面回应的。

**评测维度偏窄**。遗忘只在 TOFU / MUSE 上测，没碰 WMDP，没有重学习攻击（relearning attack），也没有概率采样下的泄漏检验。同期已经有用 leak@k 这类指标揭示"确定性解码看着忘了、多采样几次又冒出来"的工作，用 ROUGE 量记忆本身也偏表层。对一篇讲"手术式遗忘"的论文，这几块缺席挺显眼。

**有个地方我自己没完全看懂**：factorwise truncation 丢掉的那些"一个因子小、一个因子大"的混合方向，到底会不会伤到任务性能？作者只引了"平坦方向很多""优化是低维的"两篇文献做类比，没在这篇的设定下直接测被丢弃方向的贡献。可能我的理解有偏差，但从工程角度，这恰恰是换成新任务时最不确定的一环——$\gamma$ 到底该按什么调、跨模型要不要重调，文章没给出可操作的准则。落地时这是得自己趟的坑。

定位上我把它归到**几何视角下的干净整合**，不是底层突破。K-FAC 是 2015 年的老工具，Bregman / GGN、LoRA 投影都是现成的，新意在于把"保持 Hessian 的尾部特征空间"用可分离的双侧投影实现出来，同时覆盖学习与遗忘，并配一份局部保证。值不值得花时间读？如果你常要在"不动通用能力"的前提下改模型行为，值得，尤其"投影内建在参数化里、对 Adam 免疫"那段，拿来就能用。如果你只是想找一个更强的 unlearning SOTA，那得先把 MUSE 的保持列看清楚再下结论。

工程上能直接搬走的：先把"估一次保留集曲率、缓存特征基、在低曲率空间里训"这套流程套到现有 LoRA 管线上，改动集中在 delta 参数化那几行；$\mathcal{D}_{\mathrm{pres}}$ 用 256 条量级就够，成本很低；但要接受两个前提——同一份几何只在同一个 base checkpoint 上复用，模型一换就得重估，且 $\gamma$ 得按任务调。

## 收尾

聊到这，还有个更根本的问题悬着：曲率是在 $\bm{\theta}_0$ 一次性估的，可训练过程中"保持损失"这块地形自己会漂移。要不要迭代重估？重估的开销怎么摊？再往深一层，把"能力保持"整个等价于"保留集上的输出 KL"，这个代理够不够？一个模型完全可能在 256 条 FineFineWeb 上输出纹丝不动，在真实用户分布上已经悄悄变了脾气。这两件事大概就是下一批工作要啃的骨头。

即便如此，把约束从"训练时拉缰绳"改成"参数里划好跑道"，这个转向我买账。它提醒你一件事：很多时候跟优化器较劲，不如先把允许它走的那个空间定义对。

如果你也在做合规遗忘或者领域适配，这套思路值得试一次——先从那个双侧投影动手，成本比想象中低。
