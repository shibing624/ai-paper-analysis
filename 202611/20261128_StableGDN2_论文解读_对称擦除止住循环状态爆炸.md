# 擦除也能把状态擦爆：GDN-2 长上下文训练崩溃的几何根源与对称修复

你有没有碰到过这种训练事故：loss 曲线一路平稳，看着挺正常，突然某一步变成 NaN，重启、换 seed、降学习率，过几千步又在差不多的位置炸一次。翻遍数据、梯度、学习率，什么都查不出来。

说实话，我的第一反应一直是梯度爆炸或者数据里混进了脏样本。上周读到 arXiv:2611.34051 这篇论文，给了一个别扭得多的答案：模型后面什么新内容都没往记忆里写，光靠"擦除"这一个动作，就把循环状态越擦越大，直到数值溢出。

擦除，本来该是做减法的。

---

## 🎯 核心摘要

Gated DeltaNet-2（GDN-2）把线性注意力的擦除门和写入门拆成两套逐通道门，表达力上去了，长上下文训练却频繁崩。这篇论文把锅定位到擦除算子的几何结构：读取用 $b_t \odot k_t$、修改却沿 $k_t$，两个方向不平行，产生剪切（shear），让算子变成非正规矩阵，谱范数大于 1；这些方向增益跨 token 一叠加，即使后续写入全置零，状态也能指数增长。作者提出的 Stable GDN-2 把擦除门开平方后劈给两个 key 因子，恢复对称擦除与非扩张传播，再用衰减调节的残差写入补回被压掉的写入能力，证明状态范数上界从 $O(T)$ 收紧到 $O(\sqrt{T})$，且 chunkwise 并行原样保留。约 1.6B 模型上，纯循环架构 128K 平均 RULER 提升 6.80 分，混合架构九个下游任务平均准确率提升 0.62 个点。这不是新架构，是一次做得很干净的"病理诊断 + 原理性修复"——我觉得它最值钱的地方不是那 6.80 分，而是告诉我们：以后别只盯 loss 了。

## 🧠 先把家谱摆一摆：线性注意力这一支在折腾什么

线性注意力的思路不复杂：softmax attention 要存一个随长度增长的 KV cache，线性注意力干脆把历史压成一个固定大小的矩阵状态 $S_t \in \mathbb{R}^{d_k \times d_v}$，每个 token 做一次更新，解码时内存是常数，序列混合是线性复杂度。代价也直白——状态是压缩记忆，几万个 token 的关联要挤在同一个矩阵里，怎么"编辑"这份记忆就成了主战场。

最早的 Linear Transformer 是纯累加：

$$\mathbf{S}_t = \mathbf{S}_{t-1} + \bm{k}_t \bm{v}_t^\top, \qquad \bm{o}_t = \mathbf{S}_t^\top \bm{q}_t$$

写进去容易，改掉难。DeltaNet 引入 delta rule：写新值之前先把当前 key 从记忆里读出来的旧值减掉，于是更新带上一个"擦除"算子。Gated DeltaNet 再乘一个遗忘门，KDA（Kimi Delta Attention）把标量遗忘换成逐通道衰减，让每个特征维度有自己的记忆时长。说到这个，KDA 那套 DPLR 特化设计其实挺巧的——它把两个低秩向量都绑在 key 上，消掉了 chunkwise 递推里最容易在半精度下炸的除累积衰减项，顺带省了三次矩阵乘，据其技术报告在 64K 长度上接近通用 DPLR kernel 的两倍速度。

GDN-2 往前迈的那一步，是把"一个标量门同时管擦和写"松开：擦除门 $\bm{b}_t \in (0,1)^{d_k}$ 逐通道加权 key 坐标，写入门 $\bm{w}_t \in (0,1)^{d_v}$ 逐通道缩放 value 坐标，两个门各自独立参数化。原论文（Hatamizadeh 等，2026， arXiv:2605.22791）在 1.3B / 100B FineWeb-Edu 上报告了相对 Mamba-2、Gated DeltaNet、KDA、Mamba-3 的优势，长上下文 RULER 多键检索尤其亮眼。论文里那句"把逐通道衰减吸收到非对称擦除因子中"当时读着像个实现细节，谁想到"非对称"三个字就是病根。

| 模型 | 擦除门 | 写入门 | 衰减 | 擦除算子 | 无写入时状态 |
|---|---|---|---|---|---|
| Linear Transformer | 无 | 无 | 无 | 恒等 | 保持不变 |
| DeltaNet | 标量 $\beta_t$ | 同一个 $\beta_t$ | 无 | 对称 | 非扩张 |
| Gated DeltaNet | 标量 $\beta_t$ | 同一个 $\beta_t$ | 标量 $d_t$ | 对称 | 衰减 |
| KDA | 标量 $\beta_t$ | 同一个 $\beta_t$ | 逐通道 $\bm{d}_t$ | 对称 | 衰减 |
| GDN-2 | 逐通道 $\bm{b}_t$ | 逐通道 $\bm{w}_t$ | 逐通道 $\bm{d}_t$ | 非对称、非正规 | 可能指数增长 |
| Stable GDN-2 | 逐通道 $\bm{b}_t$（开平方拆两半） | 逐通道 $\bm{w}_t$ + 残差 | 逐通道 $\bm{d}_t$ | 对称 | 非扩张 |

看出规律了吧：只要擦除和写入都绑在同一个标量上，读取方向和修改方向永远是同一个 $\bm{k}_t$，擦除矩阵天然对称，谱范数不超过 1。GDN-2 一解耦，这个免费的安全保证就没了。

## 🔬 病根：读取方向和修改方向没对齐

把 GDN-2 的更新式摆出来（省去头和层的下标）：

$$\mathbf{S}_t = \bigl[\mathbf{I} - \bm{k}_t(\bm{b}_t \odot \bm{k}_t)^\top\bigr]\mathbf{D}_t\mathbf{S}_{t-1} + \bm{k}_t(\bm{w}_t \odot \bm{v}_t)^\top$$

擦除矩阵是 $\mathbf{A}_t = \mathbf{I} - \bm{k}_t \bm{a}_t^\top$，其中 $\bm{a}_t = \bm{b}_t \odot \bm{k}_t$。读旧内容时用的是 $\bm{a}_t$（被门加权过的 key），可修改动作却沿着原始 $\bm{k}_t$ 施加。这两个向量不必平行——$\bm{b}_t$ 逐通道不均匀，$\bm{a}_t$ 就被拽偏了。于是 $\mathbf{A}_t$ 一般不对称，也不正规（non-normal）：$\mathbf{A}^\top\mathbf{A} \ne \mathbf{A}\mathbf{A}^\top$。

论文在 $\bm{k}$ 和它的正交补张成的二维子空间里做了个很干净的分解。令 $\bm{a} = \mu \bm{e}_\parallel + \gamma \bm{e}_\perp$，其中 $\mu = \bm{k}^\top\bm{a}$ 是沿 key 的衰减量，$\gamma = \|\bm{a} - \mu\bm{k}\|_2$ 是偏离量，也就是剪切强度。在这组正交基下擦除算子写成：

$$\mathbf{T} = \begin{pmatrix} 1-\mu & -\gamma \\ 0 & 1 \end{pmatrix}$$

上三角那个 $-\gamma$ 就是全部麻烦：正交方向的分量被完整保留，同时往 key 方向额外"蹭"出一份。能量 $E(\mathbf{S}) = \|\mathbf{S}\|_F^2$ 因此可以增加。举个最简的例子，状态只有一列且正好落在 $\bm{e}_\perp$ 上，擦除后 $\mathbf{A}\bm{e}_\perp = \bm{e}_\perp - \gamma\bm{e}_\parallel$，能量从 $1$ 变成 $1+\gamma^2$。没有写入，凭空多出来。

Theorem 3.1 把这个增益算到底了：

$$\|\mathbf{A}\|_2 = \frac{\sqrt{\mu^2+\gamma^2} + \sqrt{(2-\mu)^2+\gamma^2}}{2}$$

并且 $\|\mathbf{A}\|_2 = 1$ 当且仅当 $\gamma = 0$，也就是 $\bm{a}$ 与 $\bm{k}$ 共线。只要门控把方向拽偏一点点，$\|\mathbf{A}\|_2 \gt 1$。这里有个特别阴的地方：矩阵的两个特征值模长都不超过 1，谱半径看着人畜无害，但算子范数（最大奇异值）大于 1。只看特征值的人会被骗过去。标量衰减也救不回来——只要 $1/\|\mathbf{A}\|_2 \lt d \lt 1$，完整转移 $\mathbf{M} = \mathbf{A}\mathbf{D}$ 仍有 $\|\mathbf{M}\|_2 = d\|\mathbf{A}\|_2 \gt 1$。

单步增益大于 1 还不算灾难，真正的杀招是跨 token 累积。若某一步的放大输出方向，恰好对上下一步的扩张输入方向，增益就乘起来。Corollary 3.2 直接构造了一条合法序列：首次写入之后所有写项全部置零（写门依然严格在 0 到 1 之间），交替使用两个互为转置的转移 $\mathbf{M}_b = \mathbf{M}_a^\top$，状态每两步回到同一方向、范数乘 $\lambda = \sigma_{\max}(\mathbf{M}_a)^2$。附录里给的具体构造取 $d = 0.99$、$\mu = 8/25$、$\gamma = 6/25$，算出

$$\lambda = d^2 \cdot \frac{19 + 6\sqrt{2}}{25} \approx 1.077533 \gt 1$$

每两步涨 7.75%，指数增长，直到溢出。等等，这个数看起来不大对吧？可 64K 的序列里有三万多个两步，这就是问题。

![图 1：GDN-2 与 Stable GDN-2 的擦除几何对比](https://arxiv.org/html/2611.34051v1/illustration.png)

*图 1（论文 Figure 1）：左半 (a) 是 GDN-2 的非对称擦除，紫色 read direction 沿 $\bm{a}_t = \bm{b}_t \odot \bm{k}_t$，黑色 modification direction 沿 $\bm{k}_t$，两者标着 Misalignment；红色 amplification 箭头直白地画出 $\mathbf{S}_t$ 比 $\mathbf{S}_{t-1}$ 更长。下方小图把这个拉伸拆成两步：$\bm{e}_t$ channel 的分量被 Maintain，$\bm{k}_t$ channel 里多出一项 $-\gamma \bm{e}_t\mathbf{S}_{t-1}$（Shear Component），于是 $(1-\mu)\bm{k}_t\mathbf{S}_{t-1} - \gamma\bm{e}_t\mathbf{S}_{t-1}$ 反而 Increase，配的柱状图也是涨。右半 (b) 是 Stable GDN-2：蓝色 $\bm{u}_t = \sqrt{\bm{b}_t}\odot\bm{k}_t$ 同时充当 read 和 modification direction，虚线弧上标着 Reduction，$\mathbf{S}_{t-1}$ 收缩到 $\mathbf{S}_t$，中间蓝色标签写明 non-expansive $\|\mathbf{S}_t\| \le \|\mathbf{S}_{t-1}\|$；小图里只剩 $1-\mu$ 的等比缩放，柱状图标着 Decrease。最下面两行分别是两个模型的完整更新式。*

一句话总结这张图：同样的逐通道擦除门，方向对齐就是收缩，方向错开就是放大。

## ⚠️ 实锤：这不是理论玩具，训练里真会炸

理论构造容易被当成"存在性证明，实际未必发生"。作者花了一整节把训练现场翻出来，我觉得这部分比定理更值得读。

设置是 64K 上下文，纯线性（Recurrent）和混合（Hybrid）两种架构，四组数据/初始化 seed 组合，覆盖预训练、后训练、以及先预训练再后训练。判定标准很朴素：loss 变 NaN 且训练无法继续。

| 架构 | 预训练失败 | 后训练失败 | 预训练 → 后训练失败 |
|---|---|---|---|
| GDN-2 Recurrent | 1/4 | 1/4 | 0/3 |
| GDN-2 Hybrid | 2/4 | 3/4 | 0/2 |

合起来 8 次预训练炸了 3 次，8 次后训练炸了 4 次；而从成功预训练 checkpoint 启动的 5 个后训练全部跑完。这个对比挺有意思——崩不崩很大程度上看初始化和数据顺序把状态推没推进那几个"扩张方向"里，而不是配置本身有问题。

回放一次失败的预训练：GDN-2 在第 2,058 步 loss 变 NaN，同一条触发序列上 GDN 和 KDA 的训练曲线都好好的。状态范数从很早就开始持续爬，到第 52,736 个 token 溢出，非有限值顺着 logits 一路传到 loss。更狠的是 Figure 2(c) 的隔离实验：只保留前 64 个 token 的更新，后面所有写项强行置零，key、门控、衰减因子原样冻住。GDN 和 KDA 在写入停止后平稳衰减，GDN-2 继续涨。等于在真实 token 序列上把 Corollary 3.2 演了一遍。

还有两个细节让我有点后背发凉。

其一是有效秩。用 $\mathrm{erank}(\mathbf{S}_t) = \|\mathbf{S}_t\|_F^2 / \|\mathbf{S}_t\|_2^2$ 衡量状态用了多少个独立维度，GDN-2 的这条曲线迅速掉到 1 附近并赖着不走。能量全挤进一个主导方向，等于一个 $128 \times 128$ 的矩阵被用成了一根向量——在数值溢出之前，模型早就已经"失忆"了，只是 loss 上看不出来。

其二更离谱：有些跑完整个训练、loss 完全正常的 run，状态里最大元素达到 $3.157 \times 10^{36}$（Pure Linear、Seed 2 的预训练）。FP32 还装得下，所以没报 NaN。附录 Table 4 里 Seed 1 的三次记录分别是 $4.383\times10^5$、$1.016\times10^6$、$7.559\times10^{11}$。看到这个数我有点怀疑自己是不是看错了量级——没看错。坦率讲，光靠 loss 曲线监控这类模型，基本等于蒙着眼睛开车。

## 🏗️ 修法：把擦除门劈成两半，再补一条带刹车的写入

思路其实一句话能讲完：既然病在两个方向不对齐，就让它们对齐。

定义 $\bm{u}_t = \sqrt{\bm{b}_t} \odot \bm{k}_t$，把擦除门开平方后拆给两个 key 因子，得到对称擦除算子：

$$\mathbf{A}_t^{\mathrm{sym}} = \mathbf{I} - (\sqrt{\bm{b}_t}\odot\bm{k}_t)(\sqrt{\bm{b}_t}\odot\bm{k}_t)^\top = \mathbf{I} - \bm{u}_t\bm{u}_t^\top$$

这个改动很克制：对角衰减量完全不变，$(\mathbf{A}_t^{\mathrm{sym}})_{ii} = (\mathbf{A}_t)_{ii} = 1 - b_{t,i}k_{t,i}^2$。也就是说作者没动门控想表达的语义，只把"读"和"改"统一到 $\bm{u}_t$ 上。用 $\bm{z}_t = \bm{w}_t \odot \bm{v}_t$ 表示门控后的 value，delta 形式写成：

$$\mathbf{S}_t = \mathbf{D}_t\mathbf{S}_{t-1} + \bm{u}_t\bigl[\bm{z}_t - (\mathbf{D}_t\mathbf{S}_{t-1})^\top\bm{u}_t\bigr]^\top$$

Proposition 4.1 随之而来的保证也很干净：$\|\bm{u}_t\|_2^2 = \sum_i b_{t,i}k_{t,i}^2 \le \|\bm{k}_t\|_2^2 = 1$，于是 $0 \preceq \mathbf{A}^{\mathrm{sym}} \preceq \mathbf{I}$，$\|\mathbf{A}^{\mathrm{sym}}\|_2 \le 1$，$\|\mathbf{M}_t\|_2 \le \|\bm{d}_t\|_\infty \le 1$。写入停了，状态就只会缩，不会涨。剪切项 $\gamma$ 被结构性消掉了，不是靠外部夹紧压住的。

但这里冒出一个新问题，作者没回避：当 $b_{t,i} \to 0$，该通道的擦除和基础写入一起消失。原本 GDN-2 解耦门控就是想让模型"擦得少但写得多"，对称化之后这俩又被绑回去了。你想想看，这不等于把刚解开的绳子又系上了吗？

于是补第二条路径：沿 $\bm{k}_t - \bm{u}_t$ 加一个残差写入，幅度由衰减调节。衰减 $\bm{d}_t$ 保留了状态能量的 $d_{t,i}^2$，那就用互补部分的平方根来定残差的额度：

$$\bm{r}_t = \sqrt{1 - \bm{d}_t^2} \odot (\bm{k}_t - \bm{u}_t)$$

$d_{t,i} \to 1$（几乎不衰减）时残差写入归零；衰减越强，允许补的写入越多。这个设计我是真的觉得挺精巧的——它把"记忆寿命"和"写入预算"用同一个物理量联系起来，而且 $\sqrt{1-d^2}$ 这个形式看着就像能量守恒里的归一化，不是拍脑袋调出来的系数。完整更新：

$$\mathbf{S}_t = \mathbf{A}_t^{\mathrm{sym}}\mathbf{D}_t\mathbf{S}_{t-1} + (\bm{u}_t + \bm{r}_t)\bm{z}_t^\top$$

![图 4：Stable GDN-2 架构与循环状态更新](https://arxiv.org/html/2611.34051v1/framework.png)

*图 4（论文 Figure 3）：(a) Block Design 是标准的残差块——RMSNorm → Stable Gated DeltaNet-2 → 残差相加 → RMSNorm → SwiGLU MLP → 残差相加，标记 $\times N$ 表示重复堆叠。(b) 上半部分是 Stable Gated Delta Rule-2 层的内部：输入 $h_t$ 分出 $q_t, k_t, v_t$（各经 Conv + SiLU 与 Linear，$q$、$k$ 再做 L2 norm），以及 Decay $D_t$（Low-rank）、Erase $b_t$（$\sigma$）、Write $w_t$（$\sigma$）三条门控支路，右侧还有 SiLU + Low-rank 的输出门，经 RMSNorm 和 Linear $W_o$ 输出。下半部分是状态更新流程：$\mathbf{S}_{t-1}$ 先过 Diagonal Decay $D_t$，再过 Symmetric Erase $\mathbf{I} - \bm{u}_t\bm{u}_t^\top$，然后依次加上 Main Write $\bm{u}_t\bm{z}_t^\top$（绿色）和 Residual Write $\bm{r}_t\bm{z}_t^\top$（橙色），得到 $\mathbf{S}_t$。两条写入路径在图上分得很清楚。*

### 上界：从 $O(T)$ 收紧到 $O(\sqrt{T})$

把更新式展开，因为 $|(\bm{u}_t + \bm{r}_t)_i| \le |k_{t,i}|$，每一步写入的贡献在传播时增益至多为 1，于是：

$$\|\mathbf{S}_T\|_F \le \|\mathbf{S}_0\|_F + \sum_{t=1}^{T}\|\bm{k}_t\bm{z}_t^\top\|_F$$

这和 Linear Transformer 的累加是同一种加法形态，零初始化、$\|\bm{v}_t\|_2 \le V$ 时给出 $\|\mathbf{S}_T\|_F \le TV$，也就是 $O(T)$。Proposition 4.2 说，加上衰减调节之后能收紧到：

$$\|\mathbf{S}_T\|_F \le \sqrt{\frac{3T}{2}}\,V$$

即 $O(\sqrt{T})$，而且不要求衰减因子一致地小于 1。这里顺带澄清一下：论文摘要里写的上界是 $O(\sqrt{T})$，正文里的 $O(T)$ 是"只做对称擦除、不做衰减调节"时的朴素加法界；不少二手转述把它记成 $O(T)$，读原文时别被带偏。附录 C.3 还专门论证了去掉衰减调节就未必能拿到与门控取值无关的平方根界。所以残差写入不只是补表达力，它连着理论保证一起做完了。

### 为什么 chunkwise 并行还能用

这块是工程上最容易被忽略、其实最要命的约束。线性注意力训练靠的是把序列切成 chunk，chunk 内用矩阵运算并行、chunk 间只传边界状态；一旦改成逐 token 串行，长上下文训练的成本就回去了。

Stable GDN-2 的转移仍是 DPLR（对角加低秩），残差路径 $\bm{r}_t\bm{z}_t^\top$ 完全由输入决定，不含状态，所以它能作为已知项塞进修正方程的右端。令 $\bm{\delta}_t = \bm{z}_t - (\mathbf{D}_t\mathbf{S}_{t-1})^\top\bm{u}_t$，chunk 内得到一个单位下三角系统：

$$(\mathbf{I}_C + \mathbf{L})\Delta = (\mathbf{I}_C - \mathbf{J})\mathbf{Z} - \mathbf{E}\mathbf{S}_{\mathrm{in}}$$

其中 $\mathbf{L} = \operatorname{tril}(\mathbf{E}\bar{\mathbf{U}}^\top, -1)$ 来自 delta 修正，$\mathbf{J} = \operatorname{tril}(\mathbf{E}\bar{\mathbf{R}}^\top, -1)$ 来自残差写入。再用 WY 辅助变量把入射状态的依赖剥开：

$$(\mathbf{I}_C + \mathbf{L})[\mathcal{W}\ \ \mathcal{U}] = [\mathbf{E}\ \ (\mathbf{I}_C - \mathbf{J})\mathbf{Z}], \qquad \Delta = \mathcal{U} - \mathcal{W}\mathbf{S}_{\mathrm{in}}$$

三角系统的规模还是 $C \times C$，系数矩阵 $\mathbf{I}_C + \mathbf{L}$ 没变，只是右端多了一项 $-\mathbf{J}\mathbf{Z}$，而且这一项可以脱离入射状态预先算好。输出和出射状态的形式也照旧（公式 24），复杂度对序列长度仍是线性的。其实吧，加了一条写入路径，却没加一层递推依赖，算子层面的改动被压到了最小。

## 📊 实验：数字能打，但也别只盯着那 6.80 分

### 设置

数据用 ProLong 的 64K 与 512K 两部分合并，TinyLlama tokenizer 重新分词，打包成统一 64K 序列，约 82.78B tokens，训练一个 epoch。两种 20 层架构：纯循环（全是线性注意力层）和混合（3 层线性 + 1 层全注意力，重复 5 次）。hidden size 2,304，FFN 中间维度 6,208，线性层 16 个头、key/value 各 128 维。参数量纯循环约 1.60B、混合约 1.55B，GDN-2 与 Stable GDN-2 在各自架构内参数量相同。

训练配置：39,473 步，global batch 32 条序列（约 2.10M token 位置/步），AdamW（$\beta_1=0.9$、$\beta_2=0.95$、wd 0.1、clip 1.0），500 步 warmup 后恒定 $3\times10^{-4}$，BF16 混合精度 + 全激活重算，每次 16 张 NVIDIA H800。主对比用初始化 seed 42、数据顺序 seed 2026，评测最终 checkpoint。

评测：九个零样本常识任务（PIQA、HellaSwag、WinoGrande、ARC-C、ARC-E、OpenBookQA、SocialIQA、BoolQ、LAMBADA），WikiText 在 8K/16K/32K/64K 窗口的困惑度与 LAMBADA 困惑度，以及 RULER 的 11 类任务在 32K/64K/128K 上的表现。

四个 baseline 的来路值得说一句：GDN-2 是直接对照，KDA 是相关的 delta-rule 代表；D-Clip 把每个衰减因子上限压到 $1/\|\mathbf{A}_t\|_2$，靠更强的衰减强行让完整转移非扩张（出自苏剑林 2026 年的博客）；$\beta$-Guard 则在需要时收缩擦除门相对 key 加权均值的偏离，以凑够非扩张的充分条件（出自 GDN-2 仓库的一个 commit）。后两个都是保留原 GDN-2 写入项的"外部夹紧"式修补，不是同期正式发表的架构论文——baseline 的这个成色，看结果时得心里有数。

去掉残差写入，主写入退化成 $u_t z_t^\top$，短任务掉 0.96 个点、检索掉 3.21；去掉衰减调节后总写入 key 变回 $\bm{k}_t$，检索直接掉到 13.53，接近腰斩。这两个数把前面那条理论线索闭合了：对称擦除给了稳定性，残差写入把被压掉的写入能力还回来，衰减调节负责约束这条新路径累计注入的能量。三条是配套的，拆开任意一条都不完整。

### 几点我想挑一挑的地方

主实验的性能对比只跑了一组 seed（42 / 2026）、一个 epoch，稳定性结论靠的是另外四组 seed 的失败统计。这两类结论的证据强度不一样，读的时候别混着用。1.6B、16 张 H800、82.78B tokens 的规模做机制验证够用，但要下"这个方法在更大模型上也稳"的结论还早。

再就是对照组的成色。D-Clip 和 $\beta$-Guard 是社区里的工程补丁，前者每次要算 $\|\mathbf{A}_t\|_2$ 去夹衰减，后者要解一个收缩约束，都属于"在原有算子上加护栏"；Stable GDN-2 是把产生增益的结构直接改掉。让这两类方法同台比准确率，赢面本来就偏向改动更彻底的一方，作者没有额外报告各方法的训练吞吐与实现开销，这块信息是缺的。另外消融里 RULER 用的 25.43 与 Table 3 的 32K/64K/128K 三档平均不是同一口径，横向比数值时要留神。

## 💡 我的判断

剥开包装看，这篇论文没有提出新的注意力架构，也没有新的训练技巧。它做了两件更基础的事：把一类反复出现的 NaN 事故，从一个"玄学调参问题"变成可以写进定理的算子几何问题；再给出一个不牺牲 chunkwise 并行、带可证上界的修复。定理 3.1 那个"特征值看着全在单位圆内、算子范数却大于 1"的观察，我觉得是全文最漂亮的一刀——它解释了为什么常见的稳定性检查（看衰减、看谱半径、看 loss）全都漏了。

对做工程的人，我觉得有三条能直接搬走：

其一，长上下文线性模型的监控面板上，该有状态范数、转移谱范数、有效秩这三项，而不是只有 loss 和 grad norm。论文里那个跑完全程、最大元素 $3.157\times10^{36}$ 的 run，loss 一直是正常的。真要等 NaN 才发现，模型早就在一个方向上"失忆"很久了。

其二，凡是想把标量门拆成逐通道门的改造，先检查擦除算子的对称性。判据不复杂：读取用的向量和修改用的向量共线吗？不共线就可能出现 $\gamma \gt 0$ 的剪切。这个检查在改造设计阶段做，比训练到几万步再回滚便宜太多。

其三，复制这套诊断流程很划算：取一小段真实序列，保留前几十个 token 的更新，后面写项全部置零，冻住 key、门控、衰减，看状态是衰减还是继续长。论文里只用了前 64 个 token 就把 GDN-2 和 GDN/KDA 分开了。几十步的计算量，能提前排掉一整类隐患。

也说说让我还不太踏实的地方。Proposition 4.2 依赖 $\|\bm{v}_t\|_2 \le V$ 和零初始化这两个前提，实际训练里 value 范数随层、随 token 变化，上界更多是定性保证而非可直接套用的数值护栏；$\sqrt{1-\bm{d}_t^2}$ 这个残差额度是巧妙的设计选择，但论文没论证它是唯一或最优的形式。还有一层更根本的：对称化之后，"擦除"和"基础写入"重新共用了 $\bm{u}_t$，GDN-2 当初解耦两门想换来的表达力到底让回去多少？消融显示补上残差写入能把分数拉回来，可这是任务分数的回填，不是表达力的直接度量。混合架构 128K 检索没赢，也暗示长到一定程度之后，瓶颈可能从"状态稳不稳"挪到"固定容量够不够"了——那是另一个问题，这篇没碰。

我自己的判断是：值花一个下午细读，尤其是第 3 节和第 4.2 节。如果你在做线性注意力、状态空间模型或者任何带固定尺寸循环状态的架构，这套"把非正规转移找出来，再从结构上消掉它"的思路，比那 6.80 分有用得多。

收尾留个问题给后来者：当状态传播被彻底约束成非扩张之后，长上下文的下一个天花板，会不会恰好就是这种"安全"本身带来的表达力天花板？这块我也还在摸索，暂时没有答案。
