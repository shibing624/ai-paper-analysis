# 多智能体加人不如加采样？516 组配置重估协作收益

假设你给一个模型只许回答一次，再让五个模型实例讨论两轮。后者赢了，能证明“讨论”有用吗？还真不能。你可能只是给第二组多花了十倍调用量；把同样的预算交给一个模型，多采几次、多数投票，或者让它把推理链写长一些，结果也许会反过来。

这篇论文盯着的就是这个评测陷阱。它没有发明新的智能体框架，而是把旧实验放到同一套资源账本上重新算了一遍。结论不算讨喜，却很值得做 Agent 系统的人停下来看看。

> **核心摘要**：论文汇总 9 项实证研究、516 个不重复多智能体配置，用 PACE 协议拆分协作、采样和测试时计算。面对单次贪心基线，多智能体平均准确率低 0.032；换成采样数或预算可比的基线后，平均差值为 -0.042，474 组对比中有 74% 打平或落后。它最有价值的地方不是宣布“多智能体无用”，而是把“协作收益”从额外计算里剥离出来，并指出证据分区、外部验证和错误去相关才是值得继续检验的正收益来源。

## 一、真正的问题不是“几个 Agent”，而是基线拿了多少钱

多智能体实验里经常出现一种不太公平的对照：一边是一次 greedy decoding，另一边是 $N$ 个 Agent、$T$ 轮交流。后者的调用量大致随 $N\times T$ 增长，前者却只跑了一次。多出来的 token、样本、工具调用和等待时间，全被塞进了“架构收益”这个筐。

可测试时计算至少有三条花法：

| 预算去向 | 实际做法 | 可能带来的收益 |
|---|---|---|
| 更多 Agent | 辩论、角色分工、顺序协作、混合聚合 | 信息交换，也可能带来趋同和开销 |
| 更多样本 | 独立生成 $k$ 次，再多数投票或 best-of-N | 降低单次采样方差，不需要交流 |
| 更多思考 | 延长 reasoning tokens，或增加迭代 | 把更多计算用于单条推理轨迹 |

如果只拿第一种和“一次回答”相比，三种效应就搅在了一起。论文把这个混乱整理成一架四级“基线阶梯”。

![图1：四级单智能体基线阶梯](https://www.mulanai.com/fs/files/1118_fdbe88d8_S1_fig1_.png)

*图 1：A、B 两级没有控制计算量；C 级固定一项具名资源，D 级进一步画出多档预算下的准确率—成本前沿。灰色与青色不是优劣标签，而是在提醒读者：不同对照能支持的结论完全不同。*

| 类别 | 单智能体基线 | 能回答的问题 | 还没控制什么 |
|---|---|---|---|
| A：单次贪心 | 一次调用，不采样 | 多智能体相对最弱基线差多少 | 样本数、token、成本等全部混杂 |
| B：采样匹配 | 独立采样 $k$ 次并聚合 | 超出样本数量的交流收益有多少 | 总 token、延迟和费用仍可能不同 |
| C：预算匹配 | 固定思考 token、迭代数或金额 | 指定预算下协作是否更划算 | 其他资源维度仍可能失衡 |
| D：Pareto 前沿 | 扫多档预算并画曲线 | 不同成本区间谁处于前沿 | 不能用一个点概括所有预算 |

我觉得这个分类比一句“请加强 baseline”实用得多。它把审稿意见变成了可执行的问题：你到底对齐了哪一项？没对齐的项目有没有报告？

## 二、PACE：给每次比较挂一张六维资源账单

PACE 的核心不是把计算压成一个神秘分数，而是保留六个彼此不能互相替代的维度：

$$
\mathbf{R}=\langle R_{\mathrm{reason}},R_{\mathrm{token}},R_{\mathrm{cost}},R_{\mathrm{lat}},R_{\mathrm{sample}},R_{\mathrm{sys}}\rangle .
$$

| 维度 | 记录内容 | 为什么单独记录 |
|---|---|---|
| $R_{\mathrm{reason}}$ | 所有调用产生的思考或 scratchpad tokens | 决定可用于内部推理的预算 |
| $R_{\mathrm{token}}$ | 输入、输出、提示词、角色头和历史消息 | 交流系统会重复携带上下文 |
| $R_{\mathrm{cost}}$ | API 花费或归一化 FLOPs | token 相同不等于价格相同 |
| $R_{\mathrm{lat}}$ | 串行执行时间与轮间同步等待 | 并发采样和多轮辩论的延迟结构不同 |
| $R_{\mathrm{sample}}$ | 生成轨迹和前向调用数量 | 用来识别集成采样收益 |
| $R_{\mathrm{sys}}$ | 检索、编译器、终端、数据库及系统提示开销 | 工具优势不能被误记成讨论优势 |

每个维度还要标成严格控制、近似匹配、已测量但未匹配、未报告四种状态。这个要求看着琐碎，实际很扎心：九项研究里，思考 token 只有 1/9 严格控制，总 token 为 2/9，成本为 1/9，样本数为 3/9，工具与脚手架为 1/9；**执行延迟是 0/9**。

![图4：九项研究的六维资源核算矩阵](https://www.mulanai.com/fs/files/1118_7b5b6e0a_S4_fig2_.png)

*图 4：绿色为严格控制，蓝色为近似匹配，黄色为测量过但未对齐，红色为未报告。大片红色说明“成本感知”在许多论文里仍停留在局部记账，而不是完整对照。*

### 一个数字，如何换一种基线就变了性质

论文用 Choi 等人的 14 个模型—基准配置做了最直观的拆解。单次贪心准确率均值是 0.670；五样本多数投票达到 0.747；五 Agent、两轮去中心化辩论则是 0.715。

![图2：把表面收益拆成采样效应与协调残差](https://www.mulanai.com/fs/files/1118_67a9ccc3_S3_fig_w.png)

*图 2：辩论相对贪心基线似乎高 0.045，但独立采样本身带来 0.076；辩论相对同数量多数投票反而低 0.031。图中的 -0.031 是相对观测投票基线的协调效应上界，不是对不可观测最优前沿的精确因果估计。*

这里有个很漂亮也很容易被误读的恒等式。记多智能体准确率为 $p_A$，单次基线为 $p_{B0}$，采样基线为 $p_{\mathrm{sampled}}$，那么换基线造成的差值变化是：

$$
\Delta_{\mathrm{gap}}=(p_A-p_{\mathrm{sampled}})-(p_A-p_{B0})=p_{B0}-p_{\mathrm{sampled}}.
$$

多智能体项 $p_A$ 直接消掉了。所以 **sampling gap 不是协作效果的测量**，它只是说明：同一个多智能体系统没变，基线因重复采样变强后，账面优势缩小了。真正该看的，是多智能体相对采样基线的差值，以及两边为此付出的成本。

### 人多不等于独立意见多

同一模型、同一提示、相近温度下，Agent 的错误往往相关。若两两相关性为 $\rho_{\mathrm{peer}}$，有效独立答案数为 $K_{\mathrm{eff}}=K/[1+(K-1)\rho_{\mathrm{peer}}]$。图 3 左面板给出的例子很直观：$K=5$、$\rho_{\mathrm{peer}}=0.50$ 时，五份答案只相当于 1.67 份独立答案。

![图3：相关投票的有效样本数与沟通阈值模型](https://www.mulanai.com/fs/files/1118_11904aa8_S3_fig_t.png)

*图 3：左图显示相关性如何吞掉团队规模；右图用错误答案变正确、正确答案变错误两个转移率构造阈值 $p^*=\kappa/(1+\kappa)$。$\kappa=0.82$ 时得到 0.45，只是对已有“45% 天花板”现象的参数化演示，不是实测证明。*

右面板背后是一个极简均值场模型：错误 Agent 每轮以 $\tau_{i\to c}$ 变正确，正确 Agent 以 $\tau_{c\to i}$ 变错误。若修复错误的能力弱于破坏正确答案的能力，基线准确率超过阈值后，沟通就会拉低均值。真实系统里的转移率显然会随题目和同伴答案变化，所以作者把它定位为可从辩论日志检验的模型，而不是普遍定律。

### 信息不增加，不等于计算没有用

论文的命题 3.1 说，如果所有私有证据在共享上下文之外都不含目标答案的信息，那么任何交流记录也不会凭空增加信息。这是数据处理不等式的直接后果。

但这里要踩一下刹车：**不增加信息，不等于多计算没有价值**。同一个共享题目上，更多采样和更长推理仍能提升答案质量；交流也可能是消耗计算的一种方式。命题真正排除的是“交流创造了原本不存在的信息”，它没有预先证明辩论一定输给同 token 的自我一致性。后者只能靠实验回答。

由此，作者留下三条可能产生正收益的路线：不同 Agent 持有互补证据；编译器、测试或数据库等外部验证器过滤错误修改；异构模型的错误足够去相关。它们都是值得检验的机制，不是这篇综述已经证明的通用配方。

## 三、516 个配置是怎么汇总出来的

证据库从五项覆盖不同资源条件的研究起步，再筛选七篇候选论文。纳入标准包括：同一测试划分上有成对 MAS/SAS 准确率、单智能体基线可辨认、评分客观且可验证。四篇进入，三篇排除。531 行原始记录里，14 行多数投票和 1 行自我一致性被当作基线剔除，留下 516 个不重复多智能体配置。

![图5：研究筛选、配置计数与数值审计流程](https://www.mulanai.com/fs/files/1118_a4e1fbb5_S5_fig_e.png)

*图 5：九项研究最终形成 358 个 A 类对比、360 个 B 类对比和 114 个 C 类对比；五类会重叠，因为同一个多智能体臂可以同时对比贪心与采样基线。作者还核对了 Tran 与 Kiela 的 336/336 个表格单元，并抽查 40 个跨研究对比，未发现数值差异。*

| 研究 | 主要匹配条件 | 配置数 | 论文汇总中的关键差值 |
|---|---|---:|---:|
| Tran and Kiela | 思考 token 相等 | 96 | -0.007，C 类 |
| Kim et al. | 迭代数匹配 | 18 | -0.042，C 类 |
| Jwalapuram et al. | 成本审计 | 107 | 对 CoT 为 -0.007；对 CoT-SC 为 -0.041 |
| Choi et al. | Agent/样本数匹配 | 14 | 对单次为 +0.045；对投票为 -0.031 |
| Wunderlich et al. | Pareto 前沿读取可比计算点 | 2 | 对自我一致性为 +0.020 |
| Ke et al. | 资源报告不足 | 29 | 对 CoT Agent 为 -0.028；对 SC Agent 为 -0.070 |
| Yang et al. | 最多 16 次生成，近似匹配 | 42 | -0.021，B 类 |
| Zhang et al. | token 与成本未匹配或未报 | 180 | 对 CoT 为 -0.058；对 SC 为 -0.073 |
| Smit et al. | 资源报告不足，取配置中位数 | 28 | 对单次约为 0；对 SC 为 -0.021 |

这张表也在提醒读者，不要只看“516”这个很大的数。不同研究的匹配条件、任务和模型并不齐整，而且 Zhang 等人一项就贡献 180 个配置。把全部行直接平均，会让它拥有很大的话语权，所以论文同时给出按研究等权、删除单项研究和多层模型三套视角。

## 四、主结果：基线变强以后，协作收益大体消失

### 描述性结果比标题更微妙

![图7：九项研究的基线阶梯与采样差距](https://www.mulanai.com/fs/files/1118_a224b8ec_S5_fig_b.png)

*图 7：蓝圆是相对单次基线的差值，红菱形是相对采样、预算匹配或 Pareto 可比基线的差值，横线连接同一系统的两种对照。九个较强基线标记里，八个位于零或零以下；唯一正值是 Wunderlich 等人的 +0.020。*

| 对比集合 | 研究数 / 对比数 | 按对比平均 $\Delta$ | 按研究等权 $\Delta$ | MAS 领先比例 |
|---|---:|---:|---:|---:|
| A：单次基线，含 Zhang | 5 / 358 | -0.032 | -0.010 | 0.37 |
| A：删除 Zhang | 4 / 178 | -0.005 | +0.003 | 0.48 |
| B：采样匹配，含 Zhang | 6 / 360 | -0.051 | -0.043 | 0.24 |
| B：删除 Zhang | 5 / 220 | -0.038 | -0.037 | 0.27 |
| C：预算匹配 | 2 / 114 | -0.012 | -0.024 | 0.32 |
| B/C 合并，含 Zhang | 8 / 474 | -0.042 | -0.038 | 0.26 |
| B/C 合并，删除 Zhang | 7 / 334 | -0.029 | -0.033 | 0.29 |

我最在意的不是 -0.042 这个点估计，而是三个更稳的模式：B/C 中 352/474 组打平或落后；删除最大贡献研究后均值仍为负；九项拥有采样或预算可比基线的研究中，八项的研究均值不为正。

但 A 类删除 Zhang 后，研究等权均值会从 -0.010 变成 +0.003。说实话，这个翻转挺重要。它说明“多智能体连单次基线都稳定打不过”并不是论文数据支持的表述；更稳妥的说法是，**相对弱基线的结果混杂且对研究构成敏感，相对强基线才持续偏负**。

五项同时报告 A/B 基线的研究里，sampling gap 全部为负：Jwalapuram 为 -0.033，Zhang 为 -0.016，Smit 为 -0.021，Ke 为 -0.042，Choi 为 -0.076；按研究等权平均为 -0.038。换基线会让账面收益缩小，这个方向在 318 组配对中相当一致。

### 多层模型：负向结果 survives，但别把它当成终审判决

作者还拟合了对比嵌套于研究的三层 REML 模型，在 log odds 尺度上处理准确率天花板压缩，并用按研究聚类的 CR2 区间。B/C 合并估计为 $\hat\beta=-0.195$，CR2 95% 区间为 $[-0.320,-0.070]$，$p=0.0076$。只看 B 类是 -0.235；删除 Zhang 后是 -0.145，区间仍为负。

![图8：B/C 类的多层模型与逐研究排除检查](https://www.mulanai.com/fs/files/1118_4840037b_S5_fig_r.png)

*图 8：左图是各研究的描述性 log odds 与合并 REML 估计，右图逐一删除八项研究。点估计始终为负，范围约 -0.233 到 -0.145，所有逐研究排除的 CR2 上界都低于零。*

敏感性检查也做得比较细：假定的题目级相关 $\varphi$ 从 0 到 0.90，点估计只在 -0.194 到 -0.195 之间移动；共享基线或共享基准的相关协方差设到 $\rho=0.80$，区间仍未跨零。只有把同一研究里不相干基准强行放进高相关的整块协方差，区间上界才越过零。

可是研究内异质性 $I_2^2$ 高达 93%，$\varphi$ 和块相关 $\rho$ 都是假定值而非原始逐题结果估计值，匹配条件又与具体论文重合。我的读法是：统计模型支持“平均方向偏负”，描述性结果才是主干，不能把 $p=0.0076$ 当成跨所有任务、模型和拓扑的终局证明。

### 成本前沿：最贵的系统，离最好还很远

Jwalapuram 等人的成本审计尤其刺眼。107 个对比里，多智能体相对贪心 CoT 的费用中位数是 8.1 倍，均值 27.1 倍，最高到 225 倍；准确率均值却低 0.007。换成五样本 CoT-SC 行后，准确率差扩大到 -0.041，费用中位数仍为 1.6 倍。

SMFR 上 GPT-5 的单基准结果更直观。

![图6：SMFR 上的成本—准确率 Pareto 前沿](https://www.mulanai.com/fs/files/1118_e39acced_S5_fig4_.png)

*图 6：CoT 为 48.5%、147 美元，CoT-SC 为 57.0%、478 美元；自动框架从 ADAS 的 20.2% 到 MAS-Orchestra 的 63.0%，MAS-Zero 花 9,239 美元只有 33.8%。人工领域工具系统 Expert MAS 达 96.51%、555 美元，与 CoT、CoT-SC 一起构成阶梯式前沿。*

看到 96.51% 很容易喊出“专家多智能体赢麻了”，但这个对照不能直接归因于交流。Expert MAS 有人工领域工具，而普通 CoT 没有同等工具；它证明的是**工具与任务工程可能远比自动对话拓扑值钱**，不是五个角色聊天必然接近满分。

还有一处必须保留的限定：Jwalapuram 原表的 CoT 与 CoT-SC 行取的是各 MAS 条目上的最佳观测基线分数，而非逐条目配对分数。因此它们是多智能体面对的上界型基线，会使差值偏向不利于 MAS。作者删除整项研究后，B/C 的 REML 结果仍为负，但这个偏差不能悄悄略过。

### 唯一的正例外，也不该被埋没

Wunderlich 等人在 MMLU-Pro、Llama-3.1-70B、1,000 道题上报告：贪心 CoT 为 64.3%，十样本自我一致性为 68.7%，辩论为 70.0%，Mixture-of-Agents 为 71.4%。在 Pareto 前沿读取的可比计算点，辩论和 MoA 分别高 1.3、2.7 个百分点。

这正好说明论文不是预先写死“多智能体永远不行”。不过这个例外只有两个多智能体臂，且是近似可比计算而非严格等预算；MoA 的提案者还是同一模型的副本，并非跨模型异构团队。它适合生成后续假设，不足以推翻其余配置的整体趋势。

### token 越多，单智能体越能追回来

Tran 与 Kiela 的数据把“more thinking”这条路线单独拉开了。主分析选 Debate 和 Sequential，96 组等思考 token 对比的均值为 -0.007；把 Subtask、Roles、Ensemble 全加入后，240 组均值为 -0.017，方向不变。

![图9：FRAMES 与 MuSiQue 上的等思考 token 扩展曲线](https://www.mulanai.com/fs/files/1118_8059ab51_S5_fig3_.png)

*图 9：横轴是全局思考 token 预算，纵轴为四个模型的平均准确率。100 token 时多智能体看似占优；从 500 token 起，单智能体在两个基准上总体追平或超过辩论和顺序协作，并随预算继续提升。*

100 token 档的 MAS 平均优势是 +0.077，但原研究记录了两边推理输出都被截断的情况，这个档位不太适合判断协作质量。500 token 时差值转为 -0.012；1,000 到 10,000 token 区间约为 -0.023 到 -0.035。Debate 单独平均是 +0.002，也并非每一臂都输，只是没有稳定超出单智能体扩展。

### “45% 后协作失效”不是普遍阈值

Kim 等人报告，当单智能体准确率超过约 45% 后，多智能体收益转负。论文没有照单全收，而是做了分段回归。四个研究、235 个配置合并后，0.45 节点上下斜率差为 +0.03，HC3 标准误 0.17，没有检测到结构性转折。

Kim 的表格确实呈现低于 0.45 时 +0.056、达到或超过 0.45 时 -0.139 的对比，但每格只有 20 个实例。Choi 相对贪心基线在阈值两边仍都为正，因为那里面还有未控制的五份采样收益。Tran 与 Jwalapuram 在阈值两边都接近零或为负。

所以 45% 更适合作为**特定任务结构与匹配条件下的现象**，不该被拿去做“模型强到 45% 就关掉多智能体”的部署规则。

## 五、多智能体到底把钱花到哪里去了

论文给出四个候选失败机制，并明确说它们是受证据启发的解释，没有在这篇工作里逐项做因果消融。

![图10：等计算下可能拉低多智能体表现的四类机制](https://www.mulanai.com/fs/files/1118_3fd5a204_S6_fig5_.png)

*图 10：上下文稀释、错误级联、多轮延迟和基线误归因。最后一项属于评测偏差，前三项才涉及系统运行；把四者混成“协作本身有害”会越过作者的证据边界。*

上下文稀释很符合工程直觉。系统提示、角色头、路由消息和不断复述的历史都会吃 token；若全局预算固定，留给每次调用真正推理的空间就被压缩。完整历史协议里，累计脚手架开销还会随轮数呈二次项增长。只传上一轮消息能缓解，却不会让开销消失。

错误级联则解释了“大家越聊越一致，却一起聊错”。没有测试、编译器或数据库反馈时，多数意见只代表相关性很高的一组模型达成共识，不代表世界真的如此。再加入顺序轮次，准确率没涨，端到端延迟还可能先涨上去。

这也把部署选择收束成一张挺克制的流程图。

![图11：在单智能体扩展与多智能体之间做选择](https://www.mulanai.com/fs/files/1118_97789317_S6_fig6_.png)

*图 11：先问单智能体采样、best-of-N 或延长推理能否解决；若不能，再看任务是否需要分区上下文、独立工具或私有状态。不需要这些结构时优先单 Agent 加工具，需要时才进入带外部验证器的多智能体方案，并报告资源向量。该流程是作者提出的启发式，尚未作为决策规则被验证。*

我认同这个顺序，但会补一条工程约束：即便任务能拆分，也要给单智能体基线同样的检索、编译器、终端和沙箱。否则测出来的可能是“有工具对无工具”，仍然不是“有交流对无交流”。

## 六、拿 PACE 改造自己的评测，最少要做哪些事

如果你正在评估一个多智能体框架，可以直接把实验改成下面这张检查表。

| 检查项 | 最低可接受做法 |
|---|---|
| 双基线 | 同时保留单次贪心与采样/预算匹配基线，前者用于复现旧口径，后者用于判断协作 |
| 资源记录 | MAS 与 SAS 都记录六维 $\mathbf R$，缺项写“未报告”，不要拿估算值补齐 |
| 脚手架核算 | 把角色提示、历史复述、路由与评判调用计入总 token 和成本 |
| 配对统计 | 报告题目数、随机种子、逐题结果或配对 bootstrap，避免只给一个平均分 |
| 工具对等 | 给单智能体相同工具与调用上限，再判断交流是否额外增益 |
| 搜索披露 | 报告架构搜索和失败图配置的计算量，不只汇报挑出的最佳图 |

配套仓库提供了 `pace` 命令行原型，能从 JSONL 轨迹做资源审计、基线分类、自我一致性前沿和辩论转移率分析。例如：

```bash
PYTHONPATH=code python -m pace audit \
  --log code/examples/sample_trace.jsonl \
  --price-in 1.0 --price-out 4.0

PYTHONPATH=code python -m pace dynamics \
  code/examples/sample_debate_dynamics.jsonl --n-boot 200

PYTHONPATH=code python -m pace report \
  --pool code/pace/examples/demo_pool.jsonl \
  --logs code/pace/examples/demo_run.jsonl \
  --system debate --n-boot 200
```

`audit` 会标出 reasoning tokens、总 tokens、成本、延迟和样本数是否失衡；`dynamics` 统计 wrong-to-right、right-to-wrong、同伴相关性和有效团队规模；`report` 则把系统准确率与同一 token 水平下的自我一致性前沿比较，并导出 rollout card 的 compute block。还有一个 hidden-profile 生成器，用来构造“单独看每份证据都会选错，合并证据才能选对”的任务，专门检验信息分区收益。

这套工具比一句“建议公平比较”前进了一步。不过它是原型，不该替代你自己的计时、价格和缓存口径审计。尤其缓存 token 怎么计费、并发任务如何计算 wall-clock，都必须在实验前写清。

## 七、我的判断：这篇值钱的是评测纪律，不是“反多智能体”立场

这篇论文的定位很清楚：它是**证据合成加评测协议**，不是新的协调算法。形式命题大多来自数据处理不等式、相关投票、Kish 设计效应和简单马尔可夫链，作者也坦承贡献在于把这些工具用于多智能体评测。真正的新信息，是把九项研究放到同一资源向量与基线阶梯下，做双基线审计、配置级台账和敏感性分析。

它的强项是克制。正面例外被保留，100 token 的截断问题被点出，45% 阈值没有被包装成定律，sampling gap 也没有被冒充成协调效应。对一篇结论偏负的综述来说，这些地方很加分。

问题也同样明显。九项研究不是系统检索得到的完整语料，起始五项按资源类型挑选，后续七篇来自初步审阅；研究、任务、模型和匹配条件彼此纠缠，无法干净识别“匹配预算”本身的因果作用。部分主分析预先挑选 Centralized 或两轮 Debate 臂，虽然有全五臂敏感性检查，分析自由度仍存在。再加上小样本单元、假定的相关参数和上界型 CoT-SC 基线，-0.042 不应被看成跨领域固定损失。

论文讨论的三条正收益路线也还没有被它自己验证。相关工作中，Ferreira 等人的[独立研究](https://arxiv.org/abs/2609.35875)覆盖 23 个小模型和 5,500 多次运行，发现生成预算匹配后辩论通常打平或输给多数投票，并用人设、温度和模型身份三条轴检验多样性，结果都不支持“认知多样性解释辩论收益”。它没有进入这篇论文的九项主合成，却提醒我们：异构模型路线仍该当作实验假设，而不是部署保证。

所以，我不会从 arXiv 2611.17610 得出“别再做 Multi-Agent”。更合理的工程结论是这样的：共享同一份题目、没有外部验证、成员错误又高度相关时，先把钱花在独立采样和更长推理上；遇到超出上下文窗口的私有信息、真正可并行的工具状态、可自动验证的子任务，再给多智能体一个严格等预算的机会。

下次看到“协作提升 5 个点”，我大概会先问三句：基线采了几次？历史复述算了多少 token？单智能体拿到同一个验证器了吗？

这三问答不出来，提升再漂亮，也还没算清账。
