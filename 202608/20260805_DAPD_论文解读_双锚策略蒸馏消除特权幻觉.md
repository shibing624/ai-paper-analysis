# DAPD: 双锚策略蒸馏——消除在策略自蒸馏中的特权幻觉

> **论文标题**: DAPD: Dual-Anchored Policy Distillation
> **arXiv ID**: [2608.01735](https://arxiv.org/abs/2608.01735)
> **作者**: Jianyu Wu, Yizhou Wang, Encheng Su, Chen Tang, Shixiang Tang
> **发布日期**: 2026年8月3日
> **领域**: 人工智能 (cs.AI)

## 一、研究背景与动机

### 1.1 在策略自蒸馏（OPSD）的兴起

后训练（Post-training）是将预训练语言模型转化为推理模型的核心环节，包括监督微调（SFT）、强化学习（RL）和蒸馏三大范式。在策略（自）蒸馏（On-Policy Self-Distillation, OPSD）正成为后训练中越来越重要的方法——它让模型在自身采样的轨迹上接受密集的 token 级教师监督，避免了固定示范或稀疏奖励的局限。

OPSD 的核心做法：
1. 给定提示 $x$ 和参考答案 $y^*$，从当前策略 $p_\theta$ 采样一条 rollout $y$
2. 在每个前缀 $y_{<t}$ 处，构造两个分布：
   - **None 分布** $p_{\text{None}} = p_\theta(\cdot | x, y_{<t})$：不使用特权信息，对应推理时的实际状态
   - **Cross 分布** $p_{\text{Cross}} = p_\theta(\cdot | x, y_{<t}, y^*)$：使用参考答案作为特权信息，使同一模型变为更强的教师
3. 用 Cross（停止梯度）监督 None：$\mathcal{L}_{\text{OPSD}} = \text{D}(\text{sg}[p_{\text{Cross}}] \| p_{\text{None}})$

### 1.2 特权幻觉问题

然而，OPSD 引发了一个严重问题——**特权幻觉（Privilege Illusion）**：学生在推理时表现得好像不可用的特权信息仍然存在，做出无依据的断言或跳过必要的推导步骤。

论文通过**行为探针**量化了这一现象：在五个 Qwen3 模型规模上，随着 OPSD 训练推进，"错误断言"（wrong claims，模型断言无依据的答案并据此构造推导）从每万次生成 13.0 次飙升到 37.0 次，同时推理 Avg@12 从 59.56 降至 53.24。

### 1.3 根因诊断：信息不对称

论文的核心洞察是：**信息不对称**——教师拥有特权信息而学生在推理时没有——才是特权幻觉的根本原因。

现有方法分为两类但均未能解决问题：
- **直接使用特权监督**（如 OPSD, SDFT, SDPO）：直接将特权教师信号传给学生
- **选择性过滤特权信号**（如 Purified OPSD, DOPD）：试图筛选或重加权教师信号以抑制特权依赖行为

论文指出这些方法的局限是结构性的：它们修改的是特权教师的信号，而非匹配教师与学生的信息可用性。

**验证实验**：保持教师不变，将学生的 None 分布替换为 Self 分布 $p_{\text{Self}} = p_\theta(\cdot | x, y_{<t}, y)$（条件于自身完整生成），由于 Cross 和 Self 都接收完整补全，信息不对称消失。结果：错误断言减少 45%，推理 Avg@12 提升 +6.22 分。

## 二、方法：Dual-Anchored Policy Distillation (DAPD)

### 2.1 核心思想

DAPD 引入 **Self 分布** $p_{\text{Self}}^s = p_\theta(\cdot | x, s_{<t}, s)$ 作为可训练的桥梁锚点：
- 与 Cross 相比，Self 是可训练的（共享策略参数）
- 与 None 相比，Self 与 Cross 信息匹配（都拥有完整补全）
- Self 填补了"无特权的可训练学生"与"有特权的停止梯度教师"之间的空白

### 2.2 三个基础目标

对每个补全来源 $s \in \{y, y^*\}$：

| 目标 | 公式 | 作用 |
|------|------|------|
| **纠缠蒸馏**（Entangled Distillation） | $\mathcal{L}_{\text{ent}}^s = \text{D}(\text{sg}[p_{\text{Cross}}^s] \| p_{\text{None}}^s)$ | 保留原始 OPSD 的特权引导传递 |
| **推理锚**（Inference Anchor） | $\mathcal{L}_{\text{infer}}^s = \text{D}(\text{sg}[p_{\text{None}}^s] \| p_{\text{Self}}^s)$ | 将 Self 对齐到 None，提供无特权条件下的锚点 |
| **特权锚**（Privileged Anchor） | $\mathcal{L}_{\text{priv}}^s = \text{D}(\text{sg}[p_{\text{Cross}}^s] \| p_{\text{Self}}^s)$ | 在双方都有特权信息时直接对齐行为 |

### 2.3 Dual-Path Anchoring (DPA)：双路径锚定

DPA 将三个目标组合为两条互补路径：

**无条件路径（Unconditioned Path）**：双方都不依赖特权信息
$$\mathcal{L}_{\text{uncond}}^{s \to \bar{s}} = \mathcal{L}_{\text{infer}}^{\bar{s}} + \mathcal{L}_{\text{ent}}^s$$

- 纠缠项将 $p_{\text{None}}^y$ 推向 $p_{\text{Cross}}^y$
- 推理锚将 $p_{\text{Self}}^{y^*}$ 推向 $p_{\text{None}}^{y^*}$
- 由于 $p_{\text{Self}}^{y^*}$ 和 $p_{\text{Cross}}^y$ 共享参数且分布近似 $p_\theta(\cdot|x, y^*)$，它们充当代理桥梁，隐式对齐 $p_{\text{None}}^y$ 和 $p_{\text{None}}^{y^*}$

**特权路径（Privileged Path）**：双方都有完整补全
$$\text{直接复用} \; \mathcal{L}_{\text{priv}}^s$$

**双路径目标**：
$$\mathcal{L}_{\text{DPA}}^{s \to \bar{s}} = \mathcal{L}_{\text{uncond}}^{s \to \bar{s}} + \mathcal{L}_{\text{priv}}^s$$

### 2.4 Dual-Source Anchoring (DSA)：双源锚定

DPA 解决了信息匹配问题，但哪个补全应该提供引导？DSA 在两个方向同时应用 DPA：

- **Rollout→Reference 方向** ($y \to y^*$)：参考答案提供引导，具有可靠性但可能偏离当前策略
- **Reference→Rollout 方向** ($y^* \to y$)：rollout 提供引导，学生可达但可能不正确

**最终 DAPD 目标**：
$$\mathcal{L}_{\text{DAPD}} = \lambda \mathcal{L}_{\text{DPA}}^{y \to y^*} + (1-\lambda) \mathcal{L}_{\text{DPA}}^{y^* \to y}$$

其中 $\lambda \in [0,1]$ 平衡参考引导与 rollout 引导的权重。

### 2.5 方法总结框图

```
┌─────────────────────────────────────────────────────────────────┐
│         DAPD 框架整体结构             │
├─────────────────────────────────────────────────────────────────┤
│     │
│  输入: 提示 x, 参考 y*, 当前策略采样 rollout y     │
│           │
│  ┌─── Dual-Source Anchoring (DSA) ───────────────────────────┐  │
│  │       │  │
│  │  方向1: y→y* (参考引导)        方向2: y*→y (Rollout引导)    │  │
│  │  ┌─── DPA ────────────┐┌─── DPA ────────────┐     │  │
│  │  │ 无条件路径:          │       │ 无条件路径:     │     │  │
│  │  │  L_ent^y + L_infer^y*│      │  L_ent^y* + L_infer^y│    │  │
│  │  │ 特权路径:            │       │ 特权路径:  │     │  │
│  │  │  L_priv^y           │       │  L_priv^y*          │     │  │
│  │  └─────────────────────┘       └─────────────────────┘     │  │
│  │          │  │
│  │  最终: L = λ·L_DPA^{y→y*} + (1-λ)·L_DPA^{y*→y}     │  │
│  └────────────────────────────────────────────────────────────┘  │
│  │
│  训练: LoRA, 前向KL + 分量裁剪(c=0.05), 无推理额外开销          │
└─────────────────────────────────────────────────────────────────┘
```

## 三、实验设置

### 3.1 模型与数据

- **模型家族**: Qwen3 系列，覆盖 1.7B / 4B / 8B / 14B / 32B 五个规模
- **训练数据**: OpenThoughts 数据集，按任务家族分领域训练
- **训练方式**: LoRA (rank=64, scale=128)，学习率 $5 \times 10^{-6}$，线性衰减 500 步，batch size 32

### 3.2 评估基准

| 任务族 | 基准 | 指标 |
|--------|------|------|
| 推理 (Reasoning) | AIME24, AIME25, HMMT25 | Avg@12 (12次采样平均正确率) |
| 编程 (Coding) | LiveCodeBench v5, BFCL v3 | Pass@1, Overall Accuracy |
| 指令遵循 (Instruct) | IFBench | IFBench Score |

### 3.3 基线方法

- **直接使用特权信号**: OPSD, SDFT, SDPO
- **选择性修改特权信号**: Purified OPSD, DOPD

## 四、实验结果

### 4.1 主要性能对比 (Qwen3-4B)

| 方法 | AIME24 | AIME25 | HMMT25 | LCB v5 | BFCL v3 | IFBench | **平均** |
|------|--------|--------|--------|--------|---------|---------|----------|
| Base | 75.56 | 65.56 | 42.50 | 52.11 | 61.38 | 29.67 | 54.46 |
| SDFT | 75.00 | 62.78 | 41.94 | 51.05 | 61.26 | 33.00 | 54.17 |
| SDPO | 70.56 | 62.78 | 40.83 | 50.53 | 61.75 | 32.67 | 53.19 |
| OPSD | 76.67 | 67.78 | 43.33 | 52.26 | 61.32 | 30.67 | 55.34 |
| Purified OPSD | 76.67 | 67.50 | 45.00 | 53.16 | 62.50 | 32.67 | 56.25 |
| DOPD | 73.61 | 65.00 | 38.89 | 50.30 | 61.47 | 31.67 | 53.49 |
| **DAPD** | **77.22** | **72.22** | **46.39** | **53.31** | **61.91** | **33.00** | **57.34** |
| Δ vs. OPSD | +0.55 | +4.44 | +3.06 | +1.05 | +0.59 | +2.33 | **+2.00** |

**关键发现**：
- DAPD 在全部六个基准上均优于 OPSD，平均提升 **+2.00** 分
- 相比过滤型方法 Purified OPSD (+1.09) 和 DOPD (+3.85)，DAPD 的结构性方案更有效
- AIME25 上获得最大提升 +4.44 分，表明在难推理任务上优势明显

### 4.2 跨规模一致性

| 模型规模 | OPSD vs Base | DAPD vs Base | **DAPD vs OPSD** |
|----------|-------------|-------------|------------------|
| 1.7B | +5.19 | +7.13 | +1.94 |
| 4B | +1.39 | +4.08 | **+2.69** |
| 8B | +0.00 | +2.41 | +2.41 |
| 14B | +0.09 | +2.13 | +2.04 |
| 32B | +0.28 | +3.06 | **+2.78** |

**核心洞察**：
- OPSD 的增益随规模增大而急剧衰减（从 1.7B 的 +5.19 降至 32B 的 +0.28），8B 及以上几乎无增益
- DAPD 在所有规模上稳定优于 OPSD，且 32B 上增益最大（+2.78）
- 大模型的 rollout 包含更多有用推理，但 OPSD 的特权幻觉更严重地抵消了这一优势；DAPD 通过信息匹配监督保留了这些增益

### 4.3 分布外泛化 (OOD)

在推理数据上训练后评估编程和指令遵循：

| 方法 | LCB v5 | BFCL v3 | IFBench | **平均** |
|------|--------|---------|---------|----------|
| OPSD | 49.32 | 61.81 | 33.67 | 48.27 |
| **DAPD** | **54.14** | 61.79 | 33.00 | **49.64** |
| Δ | +4.82 | -0.02 | -0.67 | **+1.37** |

DAPD 在 OOD 场景下同样表现更好，特别是在 LiveCodeBench v5 上大幅领先 +4.82 分。

### 4.4 定性案例分析

**AIME24 圆环切球问题**（正确答案：127）

| 方法 | 表现 |
|------|------|
| OPSD | 推导陷入困境后断言"I recall that the answer is likely 36/7"，给出错误答案 43——典型特权幻觉 |
| DAPD | 完整推导内切和外切两种情况，正确计算得 $r_i - r_o = 99/28$，$m+n=127$ |

DAPD 在步骤 250-300 将错误断言减少了 **73%**。

### 4.5 消融实验

#### 路径组件消融

| 来源 | 仅纠缠蒸馏 | +推理锚 | +推理锚+特权锚 |
|------|-----------|---------|---------------|
| Reference | 62.13 | 63.43 | 63.89 |
| Rollout | 63.33 | 64.91 | 65.09 |

两种来源均表现一致趋势：推理锚和特权锚均有增量贡献。

#### 引导来源消融

| 配置 | Avg@12 |
|------|--------|
| 仅参考引导 | 63.89 |
| 仅 Rollout 引导 | 65.09 |
| **双源结合** | **65.28** |

双源结合优于任何单一来源，验证了 DSA 设计的有效性。

#### 引导权重 $\lambda$ 的影响

| λ | 1.7B | 4B | 8B | 14B |
|---|------|------|------|------|
| 0.2 | 43.79 | **65.28** | **67.41** | **70.93** |
| 0.5 | **43.98** | 64.63 | 66.67 | 69.73 |
| 0.8 | 43.79 | 63.70 | 67.14 | 70.46 |

小模型 (1.7B) 偏好更多参考引导 ($\lambda=0.5$)，大模型 (4B+) 偏好更多 rollout 引导 ($\lambda=0.2$)。

### 4.6 无参考场景探索

| 规模 | OPSD | 双 Rollout | 验证 Rollout |
|------|------|-----------|-------------|
| 1.7B | 42.04 | 42.50 | 43.15 |
| 4B | 62.59 | 64.45 | **66.11** |
| 8B | 65.00 | 66.95 | **67.59** |

DAPD 框架可以在无参考答案的场景下工作——用独立 rollout 或经验证 rollout 替代 $y^*$，仍然获得显著增益。

## 五、训练实现细节

| 配置项 | 值 |
|--------|-----|
| LoRA rank / scale | 64 / 128 |
| 学习率 | $5 \times 10^{-6}$，线性 500 步 |
| 梯度裁剪 | 0.1 |
| 精度 | bfloat16 + 梯度检查点 |
| Batch size | 32 |
| Rollout 生成 | temp=1.1, top-p=0.95, top-k=20, max 1024 tokens |
| 训练上下文 | 20,000 tokens |
| 散度实现 | 分量裁剪前向 KL，cap=0.05 |

散度公式：
$$\ell_c(q, p) = \sum_{v \in \mathcal{V}} \min\{q_v(\log q_v - \log p_v), c\}$$

散度消融表明：分量裁剪前向 KL (Avg@12=65.28) 显著优于无裁剪前向 KL (62.50)、裁剪反向 KL (62.50) 和无裁剪反向 KL (63.33)。

## 六、核心贡献总结

1. **根因诊断**：首次明确识别"信息不对称"（特权教师与推理时学生之间）是 OPSD 特权幻觉的根本原因，而非教师质量或信号噪声
2. **DAPD 框架**：提出统一框架，通过在匹配信息可用性下增加锚定来增强原始 OPSD 目标
3. **双模块设计**：
   - **DPA（双路径锚定）**：通过无条件路径和特权路径在匹配信息条件下对齐参考与 rollout 行为
   - **DSA（双源锚定）**：平衡可靠的参考引导与学生可达的 rollout 引导

---

## 七、局限性与展望

- **计算开销**：训练时构造多个锚定分布增加计算量，但推理时无额外开销
- **超参调优**：权重可能需要跨规模/架构重新校准
- **验证信号依赖**：验证 rollout 扩展需要自动正确性信号，对开放式任务可能不可用
- **展望**：框架可自然扩展到无参考场景，且随着模型规模增大优势更加显著

---

## 八、个人点评

### 创新点
- 对特权幻觉问题给出了优雅的信息论解释，比启发式过滤方法更有理论深度
- Self 分布作为"桥梁锚点"的设计简洁而有效，不需要额外模型
- DSA 设计巧妙利用了参考与 rollout 的互补性

### 实验亮点
- 跨 5 个模型规模的系统性验证令人信服
- 特权幻觉的行为探针提供了可量化、可解释的评估维度
- 无参考场景的探索拓展了方法的适用范围

### 潜在不足
- 训练时需要同时构造 None/Cross/Self 三种分布在两个方向上的 6 个 forward pass，内存和计算开销较高
- $\lambda$ 和锚点权重的最优值依赖模型规模，实际部署需要调参
- 主要在 Qwen3 家族验证，跨架构泛化性待考察
